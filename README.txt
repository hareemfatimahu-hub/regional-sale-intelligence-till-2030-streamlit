Regional Sales Intelligence App (forecasts up to 2030)

1. Install:  pip install -r requirements.txt
2. Run:      streamlit run app.py
3. The Excel file in this folder loads automatically. You can also upload another file in the sidebar.

Tabs: Data analysis, Visualization, Predict sales, Forecast.
Forecast tab: choose "Forecast until end of" (default 2030). Data ends Dec 2020, so 2030 is 120 months ahead.
Predict sales tab: sale dates up to 2030 are supported; prices are extended along each product's yearly trend.
